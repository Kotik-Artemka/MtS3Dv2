# MtS 3D

Учебный агрегатор 3D-моделей. В каталоге четыре оригинальных STL-файла. Модели можно искать по названию, фильтровать по категории, вращать, приближать и скачивать.

## Запуск

Нужен Python 3.12 и браузер с WebGL 2. Выполните из корня репозитория:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

В PowerShell команда активации — `.venv\Scripts\Activate.ps1`.

Откройте два терминала в корне репозитория и активируйте окружение в каждом:

```bash
# Терминал 1 — Django-бэкенд
python backend/manage.py runserver 127.0.0.1:8001

# Терминал 2 — Django-фронтенд
python web/manage.py runserver 127.0.0.1:8000
```

Откройте `http://127.0.0.1:8000/`. DRF-интерфейс бэкенда доступен на `http://127.0.0.1:8001/api/`. Команды `runserver` запускают Daphne с поддержкой WebSocket. Для каталога миграции и Redis не нужны.

Если адрес бэкенда меняется, задайте `BACKEND_URL` в окружении фронтенда, например `http://127.0.0.1:9001`. При запуске на другом домене добавьте его в `DJANGO_ALLOWED_HOSTS` соответствующего проекта. Это список имён хостов через запятую.

## Связь проектов

У `backend/` и `web/` свои `manage.py`, настройки, маршруты, ASGI-приложение и список зависимостей. Проекты запускаются отдельными процессами.

- **HTTP и DRF.** Браузер запрашивает `/api/models/` у фронтенда. Фронтенд пересылает запрос в DRF бэкенда и возвращает JSON. Запросы STL проходят тем же путём. Можно также запросить отдельную модель, например `/api/models/glider/`.
- **WebSocket и Django Channels.** Браузер подключается к `/ws/catalog/` на фронтенде. Фронтенд открывает WebSocket до бэкенда и передаёт события `catalog.changed` браузеру. Получив событие, браузер повторно запрашивает каталог через REST. Бэкенд проверяет файл каталога каждые две секунды, пока сокет открыт.

Чтобы проверить обновления, оставьте сайт открытым, измените название модели в `backend/app/catalog.json` и сохраните корректный JSON. Список обновится без перезагрузки страницы. Чтобы добавить модель, положите файл в `backend/stl/` и добавьте запись в каталог с уникальным `id` и именем STL-файла.

Интерфейс находится в `web/frontend/templates/frontend/index.html`. Скрипт `catalog.js` связывает страницу с API и WebSocket, а `viewer.js` рисует модели через локальную копию Three.js.
