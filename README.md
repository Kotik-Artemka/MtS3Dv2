# MtS 3D

Учебный агрегатор 3D-моделей в виде летающей галереи. Четыре оригинальные STL-модели стоят на площадках. Экспонат можно выбрать в сцене, через поиск или через меню каталога.

## Запуск

Нужен Python 3.12 и браузер с WebGL 2. Выполните из корня репозитория:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python backend/manage.py migrate
```

В PowerShell команда активации — `.venv\Scripts\Activate.ps1`.

Откройте два терминала в корне репозитория и активируйте окружение в каждом:

```bash
# Терминал 1 — Django-бэкенд
python backend/manage.py runserver 127.0.0.1:8001

# Терминал 2 — Django-фронтенд
python web/manage.py runserver 127.0.0.1:8000
```

Откройте `http://127.0.0.1:8000/`. DRF-интерфейс бэкенда доступен на `http://127.0.0.1:8001/api/`. Команды `runserver` запускают Daphne с поддержкой WebSocket. Миграции бэкенда создают SQLite-базу и добавляют четыре экспоната. Redis не нужен.

Если адрес бэкенда меняется, задайте `BACKEND_URL` в окружении фронтенда, например `http://127.0.0.1:9001`. При запуске на другом домене добавьте его в `DJANGO_ALLOWED_HOSTS` соответствующего проекта. Это список имён хостов через запятую.

## Как летать

- **WASD** — полёт, **Пробел** — подъём, **C** — спуск, **Shift** — ускорение.
- Перетащите сцену мышью, чтобы повернуть камеру. Кнопка «Управление мышью» захватывает курсор: тогда достаточно двигать мышь, а клик выбирает экспонат под прицелом. **Esc** освобождает курсор.
- Нажмите на модель, площадку или подпись, чтобы перейти к осмотру. В отдельном окне можно вращать модель, менять масштаб, читать описание и скачать STL.
- На сенсорном экране используйте кнопки полёта и перетаскивайте сцену пальцем.

## Связь проектов

У `backend/` и `web/` свои `manage.py`, настройки, маршруты, ASGI-приложение и список зависимостей. Проекты запускаются отдельными процессами.

- **HTTP и DRF.** Браузер запрашивает `/api/models/` у фронтенда. Фронтенд пересылает запрос в DRF бэкенда и возвращает JSON. Запросы STL проходят тем же путём. Можно также запросить отдельную модель, например `/api/models/glider/`.
- **WebSocket и Django Channels.** Браузер подключается к `/ws/catalog/` на фронтенде. Фронтенд открывает WebSocket до бэкенда и передаёт события `catalog.changed` браузеру. Получив событие, браузер повторно запрашивает каталог через REST. Бэкенд проверяет записи каталога в SQLite каждые две секунды, пока сокет открыт.

Чтобы проверить обновления, оставьте сайт открытым и измените название модели через Django shell из корня проекта:

```bash
python backend/manage.py shell -c "from app.models import STLModel; STLModel.objects.filter(slug='glider').update(name='Учебный планер')"
```

Список обновится без перезагрузки страницы. Для нового экспоната положите файл `<slug>.stl` в `backend/stl/` и создайте запись `STLModel` с таким же `slug`, названием, категорией, описанием и цветом.

Интерфейс находится в `web/frontend/templates/frontend/index.html`. Скрипт `catalog.js` связывает страницу с API и WebSocket, а `gallery.js` строит площадку из объектов Three.js. `flight.js` управляет полётом, `viewer.js` — камерой в окне осмотра.
